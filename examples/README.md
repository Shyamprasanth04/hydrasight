# Sample engagement

These files are a **synthetic, fabricated** lab engagement against the
fictional target `10.10.10.15` (a stand-in for an isolated lab VM). They are
generated by [`generate_sample.py`](generate_sample.py), which exercises the
real reporting reporters in-process — no live Kali or LLM is required.

## Files

- `sample-engagement.json` — normalized `ReportModel` (+ legacy raw payload),
  produced by `reporting.json_reporter.save_json`.
- `sample-engagement.pdf` — human-readable report, produced by
  `reporting.pdf_reporter.generate_pdf`.

## Regenerate

```bash
. .venv/bin/activate
python examples/generate_sample.py
```

> ⚠️ The findings, credentials, and sessions in these artifacts are fictional
> and for documentation/schema reference only.
